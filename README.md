不是。GitHub Pages 分两种，数量限制不同：

**1. 用户 / 组织站点（User/Organization Site）—— 每个账号只能 1 个**

- 仓库名必须是 `你的用户名.github.io`
- 访问地址：`https://你的用户名.github.io`
- 一个账号只能有一个这样的仓库

**2. 项目站点（Project Site）—— 可以有无数个**

- 任何普通仓库都能开启 GitHub Pages
- 访问地址：`https://你的用户名.github.io/仓库名`
- 你有多少个仓库，就能开多少个项目站点

**简单总结**：根域名级别的主页只能有一个，但挂在子路径下的项目页面可以随便建。如果你想给多个项目分别做展示页，用项目站点就够了；如果想要多个独立的根域名站点，那才需要多个账号。

另外，无论是哪种站点，都可以绑定自定义域名（包括二级域名），所以一个账号下也能做出多个看起来独立的网站。
